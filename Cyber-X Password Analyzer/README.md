# Password Strength Checker

A beginner-friendly cybersecurity project built with Python.

## Features

- Checks password strength
- Detects:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters
- Detects common passwords
- Gives suggestions for improvement

## Technologies Used

- Python
- Regex

## How to Run

1. Clone the repository

2. Run:

python main.py

## Example

Password: Hello123

Result:
- Medium Strength
- Missing Special Character
